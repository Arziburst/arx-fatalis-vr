## Цель
Полноценное передвижение и базовые действия с контроллеров Valve Index через SteamVR Input.

## Что нужно
- SteamVR Input: action manifest и биндинги по умолчанию для Index (Knuckles)
- Разбор системы ввода Arx (`src/input/`, игровые действия)

## Задачи
- [ ] Action manifest: move, turn, jump, crouch, interact, inventory, map, book, menu, combat, magic
- [ ] Плавное передвижение стиком относительно головы или контроллера (настройка)
- [ ] Snap turn и smooth turn
- [ ] Прыжок, присед (кнопкой и реальным приседанием), скрытность
- [ ] Взаимодействие «указкой» как временная замена мыши
- [ ] Биндинги по умолчанию для Index, совместимость с другими контроллерами через SteamVR

## Критерии готовности
- Первую локацию (тюрьма гоблинов) можно пройти без клавиатуры и мыши

## Зависимости
Эпики «VR-рендер», «Трекинг головы и камера».
