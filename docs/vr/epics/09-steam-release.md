## Цель
Опубликовать VR-версию в Steam как бесплатное отдельное приложение, которое работает только при наличии оригинальной Arx Fatalis (app 1700) на аккаунте.

## Что нужно
- Разрешение правообладателя Arx Fatalis (Arkane / ZeniMax / Microsoft) на использование названия и привязку к оригиналу
- Согласование с командой Arx Libertatis (GPLv3+ с дополнительными условиями)
- Аккаунт Steamworks (взнос $100 за приложение), страница магазина, проверка Valve

## Задачи
- [ ] Письмо правообладателю с описанием проекта и видео прототипа
- [ ] Связаться с командой Arx Libertatis: совместимость Steamworks с GPL, атрибуция
- [ ] Решить вопрос со Steamworks SDK: не линковать проприетарную библиотеку или получить исключение по лицензии
- [ ] Проверка наличия игры: движок находит установленную Arx Fatalis (Steam library, `appmanifest_1700.acf`) и берёт данные оттуда; ресурсы игры **не** распространяются
- [ ] Название без нарушения товарного знака (например, «Arx Libertatis VR»), если разрешение не получено
- [ ] Публичный репозиторий с исходниками (требование GPL)
- [ ] Страница магазина: описание, скриншоты, трейлер, системные требования, пометка «требуется Arx Fatalis»
- [ ] Сборка для Steam (depot), бета-ветка для тестеров

## Критерии готовности
- Приложение прошло проверку Valve и доступно бесплатно в магазине
- Без установленной Arx Fatalis приложение показывает понятное сообщение и ссылку на магазин

## Зависимости
Играбельная версия (эпики 1–8). Юридические задачи можно начинать сразу после рабочего прототипа.
