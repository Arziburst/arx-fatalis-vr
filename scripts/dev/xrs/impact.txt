# The impact map of the CI game checks (#522): which checks a pull request runs besides the core.
#
# A pull request runs the core, every name of a line whose glob matches a path it changes, and the .xrs files it
# changes or adds themselves (a read-back selects its sequence). A changed path that no line matches runs
# everything: a new folder or file is safe until it gets a line here. A push to main, a manual run with suite=full
# and a pull request with the label full-ci run everything, and so does the merge gate before every merge.
#
#   core: <name> ...                 run on every pull request
#   <path glob> -> <name> ...        a change of a matching path also runs these
#   <path glob> -> *                 ... runs everything (the harness every check stands on)
#   <path glob> -> core              ... is covered by the core alone
#
# A name is a sequence (scripts/dev/xrs/<name>.xrs) or smoke-test / spell-drawcheck. A glob is a repository path
# with / and the wildcards of PowerShell's -like, any case: * also crosses folders (src/gui/* is the whole folder).
# Several lines may match one path: their names add up, and one '-> *' among them runs everything.
# A new sequence needs a line (or a place in core): the coverage check of test-ci-smoke.ps1 fails a sequence that no
# line names, and a name that is no sequence. Docs: docs/vr/TESTING.md "The CI gate".

# --- The core: every pull request ----------------------------------------------------------------------------------
# Start-up, a level load, a save load, the head, movement, input, the full body, the HUD, the menus and the VR
# session's life, with the two draw checks: fast checks that a break of a file every feature touches
# (CommandChannel.cpp, Config.cpp, VRSystem.cpp, CMakeLists.txt) shows up in. The save library runs with them (most
# core sequences load a save). arms-follow (the full body) is here also because a red main once failed it on pull
# requests that did not touch the body (#489).
core: smoke-test spell-drawcheck
core: first-run look-around walk-forward snap-turn recenter real-input arms-follow
core: hud-frame-flat menu-pointer level-load-hang vr-session-end vr-session-loss
